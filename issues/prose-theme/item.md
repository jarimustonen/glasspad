# Prose/reading theme in the --gp-* design system

## Description

A first-class **prose/reading theme** (serif reading column, ~720px) beside the
existing data-dashboard theme — one `--gp-*` system, two themes. Editorial
content (articles) gets a native look instead of a separate stylesheet.

Foundation for the markdown+template render path (see `markdown-template-render`).

Part of the agent→browser-HTML consolidation. Full design + rationale: homebase `issues/glasspad-html-consolidation/design.md` (Option D). These features make glasspad the single canonical agent→HTML surface.
Ref: DESIGN.md.
