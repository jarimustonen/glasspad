# Markdown document rendering

_Source: pad content types_

## Description

Add support for rendering Markdown documents in Glasspad. AI agents should be able to push a markdown document (or collection of documents) and have it rendered with proper formatting, syntax highlighting, and navigation.

## Scope

- New section type or pad mode for markdown content
- Full CommonMark + GFM rendering (headings, lists, tables, code blocks, links, images)
- Syntax highlighting for fenced code blocks
- Table of contents / document navigation for long documents
- Support for multiple documents in a single pad (tabbed or sidebar navigation)
- Responsive layout suitable for reading

## Out of Scope

- Live collaborative editing (read-only rendering)
- Markdown editing UI
