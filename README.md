# glasspad

AI-friendly scratchpad for rich data views. A lightweight web service that lets AI agents (Claude Code, OpenClaw, etc.) create and share visual content — dashboards, charts, interactive UIs — via a simple API.

## Concept

1. AI agent POSTs content (HTML, data, chart spec) to the API
2. Gets back a URL
3. User opens the URL and sees the rendered view

No complex setup. No authentication dance. Just: push data, get a link.
